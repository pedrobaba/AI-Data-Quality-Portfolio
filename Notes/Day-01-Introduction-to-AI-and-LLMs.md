## Learning objectives

- Identify the main criteria used to evaluate AI-generated responses.

## 1. Artificial Intelligence
Artificial Intelligence is the field of creating computer systems that can perform tasks commonly associated with human intelligence, such as understanding language, recognising images, making predictions and generating content.

## 2. Machine Learning and Deep Learning
- **Artificial Intelligence:** The broader field of building systems that perform intelligent tasks.
- **Machine Learning:** A branch of AI in which systems learn patterns from data.
- **Deep Learning:** A branch of machine learning that uses multi-layered neural networks.

## 3. Large Language Models
A Large Language Model (LLM) is an AI model trained on large amounts of text so it can process and generate language. Examples include GPT, Gemini, Claude and Llama.

LLMs generate text by predicting likely next tokens based on patterns learned during training and the context supplied at inference time.

## 4. A simplified response-generation process
1. The user submits a prompt.
2. The input is tokenised into smaller units.
3. The model processes the tokens using its learned parameters.
4. It predicts a likely next token.
5. It continues generating tokens until the response is complete or a stopping condition is reached.

This is a simplified explanation; actual model architectures and decoding methods can be more complex.

## 5. Key terminology

| Term | Meaning |
|---|---|
| Prompt | Instructions or input supplied to an AI model |
| Token | A unit of text processed by a model |
| Tokenisation | Converting text into tokens |
| Parameters | Learned numerical values that shape model behaviour |
| Context window | The amount of input/output context a model can handle |
| Inference | Using a trained model to generate an output |
| Training data | Data used during model training |
| Hallucination | False, fabricated or unsupported generated information |

## 6. AI response evaluation criteria
- **Accuracy:** Is the information correct and supported by reliable evidence?
- **Relevance:** Does the response address the user's actual request?
- **Instruction following:** Does it obey explicit constraints such as format, length and number of items?
- **Completeness:** Does it include the information needed to satisfy the request?
- **Clarity:** Is it understandable and well organised?
- **Safety:** Does it avoid harmful or otherwise disallowed content?

## 7. Lessons from practice
- A response can contain correct information and still fail an explicit instruction.
- Relevance and completeness are not the same: a response can be on-topic but omit something important.
- Extra information is not automatically a hallucination. It becomes a factuality problem when it is false, fabricated or unsupported.
- The original prompt is the reference point for judging instruction following.
- A longer answer is not necessarily a better answer.
