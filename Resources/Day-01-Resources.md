# Day 1 — Introduction to AI and LLMs Resources

**Date studied:** 11 November 2026

## Learning materials
The lesson was completed as part of the self-directed 21-day AI Evaluation & Data Annotation programme.

## Free reference reading
- [Google Machine Learning: Glossary](https://developers.google.com/machine-learning/glossary) — reference for foundational machine-learning terminology.
- [IBM: What is artificial intelligence (AI)?](https://www.ibm.com/think/topics/artificial-intelligence) — overview of AI concepts and applications.
- [OpenAI: Tokenizer](https://platform.openai.com/tokenizer) — interactive way to see how text can be split into tokens.

## Practical tools
- ChatGPT — prompt-response evaluation practice.
- Google Docs or Markdown — documenting notes and evaluation decisions.
- GitHub — version control and portfolio evidence.

## Key concepts reviewed
- Artificial Intelligence
- Machine Learning
- Deep Learning
- Large Language Models
- Prompts and tokens
- Tokenisation
- Inference
- Context window
- Hallucinations
- Accuracy, relevance and instruction following

## Learning goal
Build a basic understanding of LLMs and establish a repeatable method for evaluating responses against prompt requirements and factual evidence.

## Portfolio application
The Day 1 practice project records four response-evaluation exercises, the decisions made, corrections received and the assessed score.
