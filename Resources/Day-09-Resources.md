# Day 09 – Text Classification and Categorisation Resources

These resources provide further reading on text classification, predefined labels, classification workflows, and model-based text categorisation.

## 1. Google – Text Classification Guide

https://developers.google.com/machine-learning/guides/text-classification

Topics:
- Text classification fundamentals.
- Topic classification.
- Sentiment analysis.
- Data preparation.
- Model training and evaluation.

Why it is useful:

Explains how text classification works and how predefined categories are used to organise text.

## 2. Hugging Face – Text Classification

https://huggingface.co/tasks/text-classification

Topics:
- Text classification.
- Sentiment analysis.
- Classification examples.
- Different classification applications.

Why it is useful:

Provides practical examples of assigning labels to text.

## 3. Hugging Face – Transformers Text Classification Guide

https://huggingface.co/docs/transformers/tasks/sequence_classification

Topics:
- Sequence classification.
- Dataset preparation.
- Label mappings.
- Model training.
- Classification inference.

Why it is useful:

Shows how text classification is implemented in machine learning systems.

## 4. Hugging Face – Zero-Shot Classification

https://huggingface.co/docs/inference-providers/en/tasks/zero-shot-classification

Topics:
- Candidate labels.
- Zero-shot text classification.
- Multi-label classification settings.
- Classification scores.

Why it is useful:

Demonstrates how text can be classified using candidate categories, including configurations that permit multiple labels.

## 5. Google AI Edge – Text Classifier

https://developers.google.com/edge/mediapipe/solutions/text/text_classifier

Topics:
- Text classifier inputs and outputs.
- Category labels.
- Classification scores.
- Model configuration.

Why it is useful:

Provides another practical view of how classification systems assign categories to text.

---

## Recommended Study Order

1. Read Google's text classification guide.
2. Explore the Hugging Face text classification task.
3. Study sequence classification and label mappings.
4. Explore zero-shot classification.
5. Review Google's text classifier documentation.

## Important Note

Machine learning model predictions are not automatically ground truth.

In professional annotation work, human annotators must still follow the project's instructions, verify evidence, and escalate unresolved cases.
