# Day 6 – Learning Resources

## Topic
Human Feedback, Preference Ranking and Reinforcement Learning from Human Feedback (RLHF)

This document contains the learning materials used to support Day 6.

## 1. Introduction to RLHF

### Hugging Face – Illustrating Reinforcement Learning from Human Feedback (RLHF)

Link:
https://huggingface.co/blog/rlhf

Purpose:
- Understand the basic RLHF process.
- Learn how human preferences are collected.
- Understand reward models.
- Learn how reinforcement learning is used to optimise language models.

Recommended for:
Beginners who want a practical explanation of RLHF.

## 2. Human Feedback and Preference Ranking

### OpenAI – Training Language Models to Follow Instructions with Human Feedback

Link:
https://arxiv.org/abs/2203.02155

Authors:
Long Ouyang and colleagues.

Published:
2022.

Purpose:
- Understand how human evaluators compare AI-generated responses.
- Learn how preference-ranking data is collected.
- Understand how human feedback contributes to model training.
- Explore the InstructGPT training approach.

Recommended sections:
- Abstract
- Introduction
- Methods and data collection
- Results

## 3. Foundational Research on Human Preferences

### Deep Reinforcement Learning from Human Preferences

Link:
https://arxiv.org/abs/1706.03741

Authors:
Paul Christiano and colleagues.

Published:
2017.

Purpose:
- Understand how human comparisons can provide feedback to learning systems.
- Explore how preference data can be used to learn reward functions.
- Understand the foundations of learning from human preferences.

Recommended for:
Further reading after understanding the basic RLHF process.

## 4. Practical Reward Modelling

### Hugging Face – Reward Modeling Documentation

Link:
https://huggingface.co/docs/trl/main/en/reward_trainer

Purpose:
- Understand how preferred and rejected responses are represented.
- Learn how reward models are trained using preference pairs.
- Explore the technical structure of preference datasets.

Recommended for:
Readers who want to understand how preference-ranking data is used in practical model training.

## 5. OpenAI – InstructGPT Project

### Official OpenAI GitHub Repository

Link:

Purpose:
