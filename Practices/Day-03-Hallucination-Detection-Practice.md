# Day 3: Hallucination Detection Practice

**Date:** 14 November 2026  
**Project:** AI Hallucination Detection and Factual Accuracy  
**Type:** Independent Portfolio Exercise

## 1. Project Objective

The objective was to evaluate AI-generated responses, identify factual errors and unsupported claims, and provide evidence-based feedback.

## 2. Exercise 1: Fabricated Information

**Prompt:** Who developed Python, and when was it first released?

**AI Response:**

"Python was developed by James Gosling and first released in 1991. It was originally created at Sun Microsystems."

### My Evaluation

- Factual accuracy: No.
- Hallucination: Yes.
- Incorrect claims: Python was developed by James Gosling and originally created at Sun Microsystems.
- Better answer:

"Python was created by Guido van Rossum. Development began in December 1989, and Python was first released in 1991."

**Assessment:** Mostly correct. I identified the hallucination but initially confused the development date with the release date in my correction.

## 3. Exercise 2: Unsupported Statistics

**Prompt:** What percentage of software testers use automation tools?

**AI Response:**

"Approximately 96% of software testers worldwide use automation tools daily, according to the 2025 Global QA Research Report."

### My Initial Evaluation

I initially accepted the statistic as accurate and suggested a range of 77%–97%.

### Corrected Evaluation

- Evaluation outcome: Unverified.
- Reason: The response provides a precise statistic and names a research report without verifiable supporting evidence.
- Required action: Independently verify the statistic and the cited report before accepting the claim.

**Assessment:** Incorrect initial evaluation.

**Lesson:** A plausible statistic is not sufficient evidence of factual accuracy.

## 4. Exercise 3: Extra Information vs Hallucination

**Prompt:** Who created JavaScript?

**AI Response:**

"JavaScript was created by Brendan Eich in 1995. It became one of the most widely used programming languages for web development."

### My Evaluation

- Extra information: Brendan Eich developed the initial prototype in approximately ten days while working at Netscape.
- Hallucination: No.
- Reason: The additional historical context does not automatically make the response a hallucination.

**Assessment:** Correct.

**Lesson:** Additional information should be judged by factual accuracy, not simply by whether it was requested.

## 5. Exercise 4: Mixed Factual Accuracy

**Prompt:** What is an API?

**AI Response:**

"An API is a programming language used only for building websites. It allows software applications to communicate with each other."

### My Initial Evaluation

I initially considered the response completely correct.

### Corrected Evaluation

| Claim | Evaluation |
|---|---|
| An API is a programming language used only for websites. | Incorrect |
| An API allows software applications to communicate. | Correct |

**Better answer:**

"An API is a set of rules or an interface that allows different software applications to communicate and exchange information."

**Assessment:** Incorrect initial evaluation.

**Lesson:** A response can contain correct and incorrect claims at the same time.
