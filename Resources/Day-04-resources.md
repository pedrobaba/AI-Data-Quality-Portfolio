## Key Terms

| Term | Meaning |
|---|---|
| Instruction Following | Ability to obey user instructions and constraints |
| Factual Accuracy | Whether information is correct and supported |
| Relevance | How directly a response addresses the request |
| Completeness | Whether all requested information is included |
| Clarity | How understandable and well-organised a response is |
| Evaluation Rubric | A defined set of criteria used to assess quality |
| Response Ranking | Comparing responses and selecting the better one |
| Quality Rating | Assigning a score based on evaluation criteria |

## Evaluation Checklist

Before rating an AI response, ask:

- Did it follow all explicit instructions?
- Are its claims factually correct?
- Does it directly answer the user's request?
- Does it include all requested information?
- Is it clear and suitable for the intended audience?
- Does the evaluation follow the project's rubric?

## Important Note

The five-point rating scale used in this lesson is illustrative. Actual annotation and AI evaluation projects may use different scales, labels, weighting systems, and guidelines.

Always follow the project's official instructions.
