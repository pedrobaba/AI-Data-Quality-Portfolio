
# Day 5 Learning Journal

## Topic: Instruction Following and Prompt Constraints

### What I Learned

Today I learned how to evaluate AI-generated responses based on the instructions provided by users.

I understood that an AI response can be relevant, readable, and factually correct but still fail when it violates specific user requirements.

I learned about four instruction categories:

- Explicit instructions
- Implicit instructions
- Formatting constraints
- Content constraints

### Practical Experience

I completed three instruction-following assessment exercises.

The exercises tested my ability to:
- Identify prohibited content.
- Detect unsupported claims.
- Check word and sentence limits.
- Recognise technical jargon.
- Identify partial instruction compliance.
- Provide evidence-based feedback.

### Challenges Encountered

My main challenge was identifying all instruction violations in an AI response.

In some exercises, I identified the obvious problem but overlooked other requirements, such as exact word counts and sentence limits.

I also initially classified one partially compliant response as a complete failure before correcting my evaluation.

### Lessons Learned

1. I should evaluate every instruction independently.
2. I should not stop after identifying the first error.
3. I must verify word counts and sentence counts.
4. I should distinguish response quality from instruction compliance.
5. Evaluation feedback should explain exactly what went wrong.
