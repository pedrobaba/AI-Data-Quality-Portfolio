## 2. What Is Artificial Intelligence?

Artificial Intelligence is the ability of computer systems to perform tasks that typically require human intelligence.

Examples include:
- Understanding natural language.
- Recognising images.
- Making predictions.
- Generating text.
- Answering questions.

## 3. Understanding Machine Learning and Deep Learning

- **Artificial Intelligence:** The broader field of creating intelligent computer systems.
- **Machine Learning:** A branch of AI that allows systems to learn patterns from data.
- **Deep Learning:** A branch of machine learning that uses multi-layered neural networks.

## 4. What Is a Large Language Model?

A Large Language Model (LLM) is an AI model trained on large amounts of text to understand and generate human-like language.

Examples include:
- GPT
- Gemini
- Claude
- Llama

LLMs generate responses by predicting likely sequences of tokens based on learned patterns and the available context.

## 5. How LLMs Generate Responses

A simplified process:

1. A user submits a prompt.
2. The input is tokenised into smaller units.
3. The model processes the tokens using learned parameters.
4. It predicts the next token.
5. It continues generating tokens until the response is complete.

## 6. Important AI Terminology

| Term | Meaning |
|---|---|
| Prompt | Instructions or input given to an AI model |
| Token | A unit of text processed by a model |
| Tokenisation | Breaking text into tokens |
| Parameters | Learned numerical values used by a model |
| Context window | Amount of information a model can process in context |
| Inference | Generating an output using a trained model |
| Training data | Data used to train a model |
| Hallucination | Generated information that is false, fabricated or unsupported |

## 7. AI Response Evaluation Criteria

An AI evaluator assesses responses against specific criteria.

### Accuracy
Does the response contain correct and verifiable information?

### Relevance
Does it address the user's actual question?

### Instruction Following
Does it obey the explicit requirements in the prompt?

### Completeness
Does it include the information needed to satisfy the request?

### Clarity
Is the response understandable and well organised?

### Safety
Does it avoid harmful, inappropriate or unsafe content?

## 8. Important Lessons

- A response can be accurate but fail to follow instructions.
- A relevant response may still be incomplete.
- Extra information is not automatically a hallucination.
- A hallucination involves false, fabricated or unsupported information.
- Responses should be evaluated against the original prompt and reliable evidence.
- Longer responses are not automatically better responses.
