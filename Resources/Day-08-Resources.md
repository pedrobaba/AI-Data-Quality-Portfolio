# Day 08 – Data Annotation Resources

These resources support the fundamentals of data annotation, text classification, sentiment analysis, and labelled datasets.

## 1. Hugging Face – Text Classification

https://huggingface.co/tasks/text-classification

Topics:
- What text classification means.
- Common text classification applications.
- Sentiment analysis.
- Classification examples.

Why it is useful:
Provides a practical introduction to how text is assigned categories or labels.

## 2. Hugging Face – Text Classification Guide

https://huggingface.co/docs/transformers/tasks/sequence_classification

Topics:
- Preparing text datasets.
- Text classification workflows.
- Sentiment classification.
- Model evaluation.

Why it is useful:
Shows how labelled text datasets are used in machine learning workflows.

## 3. Amazon SageMaker – Data Labeling with a Human-in-the-Loop

https://docs.aws.amazon.com/sagemaker/latest/dg/data-label.html

Topics:
- Human data annotation.
- Labeling workflows.
- Training data preparation.
- Human review.

Why it is useful:
Explains how human annotators contribute to creating labelled datasets.

Note:
Amazon SageMaker Ground Truth is no longer open to new customers, according to the current AWS documentation. This resource is included for learning purposes.

## 4. AWS – Creating High-Quality Annotation Instructions

https://aws.amazon.com/blogs/machine-learning/create-high-quality-instructions-for-amazon-sagemaker-ground-truth-labeling-jobs/

Topics:
- Writing clear annotation instructions.
- Reducing ambiguity.
- Using examples.
- Testing and improving annotation guidelines.

Why it is useful:
Provides practical guidance on creating instructions that help annotators produce consistent labels.

## 5. Google – Machine Learning Crash Course

https://developers.google.com/machine-learning/crash-course/

Topics:
- Machine learning fundamentals.
- Datasets and data preparation.
- Classification.
- Model evaluation.
- Bias and fairness.

Why it is useful:
Provides additional background on how datasets and labels fit into machine learning.

## Recommended Study Order

1. Read the Hugging Face text classification overview.
2. Review the Hugging Face sequence classification guide.
3. Study the AWS guidance on annotation instructions.
4. Review the human-in-the-loop labeling workflow.
5. Explore Google's machine learning fundamentals.
