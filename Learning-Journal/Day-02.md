## Things I Learned

- A token is a unit of text processed by a language model; it is not necessarily a whole word.
- LLMs commonly generate text through successive next-token predictions.
- The context window determines how much information can be processed at one time.
- Temperature influences the variation of token selection.
- Fluent or factually correct text can still fail to follow the user's instructions.
