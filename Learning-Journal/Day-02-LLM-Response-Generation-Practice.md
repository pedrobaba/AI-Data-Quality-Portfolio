# Day 2 Project: LLM Response Generation and Evaluation Practice

**Programme:** 21-Day AI Evaluation & Data Annotation Programme  
**Date:** 12 November 2026  
**Project Type:** Independent Portfolio Exercise

## Objective

Evaluate two AI-generated responses to the same prompt, separating instruction following, accuracy, and clarity.

## User Prompt

> Explain what an API is in exactly two sentences. Use simple English.

## Responses

### Response A

An API is a way for two software applications to communicate with each other. It allows one application to request information or services from another application.

### Response B

An API is a way for two software applications to communicate. It allows applications to exchange data. APIs are commonly used in web and mobile applications.

## Evaluation

| Criterion | Response A | Response B |
|---|---|---|
| Instruction Following | Pass — exactly two sentences | Fail — three sentences |
| Accuracy | Pass | Pass |
| Clarity | Pass | Pass |
| Overall Decision | Preferred | Not Preferred |

## Evaluation Reasoning

**Response A:** It satisfies the requested two-sentence limit and gives a clear, factually sound explanation in simple English.

**Response B:** Its explanation is also clear and factually sound, but it contains three sentences and therefore violates the explicit two-sentence requirement.

## Preferred Response

**Response A**

**Reason:** Response A satisfies all the user's requirements. It provides an accurate and clear explanation in exactly two sentences. Response B is also accurate and clear, but it violates the explicit sentence-count constraint.

## Evaluator Lesson

Factual accuracy alone is not enough to establish response quality.

Evaluators should assess each dimension independently before making an overall decision.

A response can be accurate but still fail because it ignores a specific instruction, format, length, or output constraint.
